
## 🐛 Troubleshooting

### Backend not responding
```bash
# Check pod status
kubectl -n gearup get pods -l app=backend

# Check logs
kubectl -n gearup logs deployment/backend -tail=50

# Restart
kubectl -n gearup rollout restart deployment/backend
```

### Cannot connect to API from frontend
1. Check frontend `.env`: Should have `VITE_API_BASE_URL=http://localhost:30080/api`
2. Check backend health: `curl http://localhost:30080/actuator/health`
3. Check services: `kubectl -n gearup get svc`

### Database connection issues
```bash
# Connect to MySQL
$pod = kubectl -n gearup get pods -l app=mysql -o jsonpath='{.items[0].metadata.name}'
kubectl -n gearup exec -it $pod -- mysql -u gearup_user -pAnu@2001 gearup

# Check tables
SHOW TABLES;
SELECT COUNT(*) FROM users;
```

## 📞 Need Help?

**Check logs first**:
```bash
kubectl -n gearup logs deployment/backend --tail=100
kubectl -n gearup logs deployment/frontend --tail=100
```

**Common issues**:
- 500 errors → Check backend logs for exceptions
- Cannot reach API → Verify NodePort (30080) is exposed
- Database errors → Check MySQL pod and logs
- Email errors → Check dev mode is enabled (Spring profile = dev)
